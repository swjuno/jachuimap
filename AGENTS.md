## Stack

| Layer | Technology |
|---|---|
| Framework | **Next.js 16** App Router (this project was scaffolded with Next.js 16 / React 19 — NOT Next.js 14) |
| Language | **TypeScript strict** (`"strict": true` in `tsconfig.json`) |
| Styling | **Tailwind CSS v4** (PostCSS plugin, no config file needed) |
| Icons | **Lucide React** |
| Runtime target | Node.js (server), browser (client) |

## File-responsibility map — one concern per module

| File | Allowed to do | NOT allowed to do |
|---|---|---|
| `lib/scoring.ts` | Pure, deterministic scoring math. Take `InfrastructureData`, return `ScoreBreakdown`. | No `fetch`, no process.env reads, no side-effects |
| `lib/kakao.ts` | Server-side Kakao REST API calls (keyword search, coordinate lookup). | No UI, no scoring logic |
| `data/subway-lines.ts` | Static mapping: line name → stations, express flag. Immutable. | No runtime I/O |
| `types/score.ts` | Shared TypeScript interfaces only. No runtime code. | No logic, no imports from other project modules |
| `components/*` | Client UI components (`'use client'` where state/events needed). Small and focused. | No direct API calls; receive data via props |
| `app/` | Next.js routing only — layouts, pages, route handlers. Orchestrate data fetching and pass down. | No raw business logic inline |

## Coding constraints

1. **Early returns** — validate at the top of every function; avoid deeply nested `if/else`.
2. **Zero over-engineering** — do not create an abstraction without at least two reuse sites.
3. **Coordinates** — Kakao `radius=500` is treated strictly as a **straight-line (직선거리) 500 m radius**. Never inflate or deflate this value in scoring or UI copy.
4. **Server Components by default** — add `'use client'` only when the component uses state, event handlers, or browser APIs (`useState`, `useEffect`, `window`, etc.).
5. **`params` is a Promise** — in Next.js 16, always `await params` before destructuring: `const { id } = await params`.
6. **`server-only` guard** — add `import 'server-only'` at the top of `lib/kakao.ts` to prevent accidental client-side imports.
7. **No `any`** — use `unknown` + type narrowing, or explicit interfaces.
8. **Tailwind v4** — utilities are auto-detected; no manual `content` config needed. Use CSS variables for design tokens in `app/globals.css`.
